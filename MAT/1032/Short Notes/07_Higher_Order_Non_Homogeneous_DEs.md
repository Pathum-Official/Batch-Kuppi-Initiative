# 07. Higher Order Non-Homogeneous DEs

> [!NOTE]
> **Background & Prerequisites (අවශ්‍ය මූලික දැනුම)**
> *   මෙම පාඩම කිරීමට පෙර අනිවාර්යයෙන්ම කලින් පාඩම (Homogeneous DEs) හොඳින් දැන සිටිය යුතුය.
> *   General Solution (සාමාන්‍ය විසඳුම) ලියන්නේ: **$y = y_c + y_p$** ලෙසයි.
> *   $y_c$ (Complementary Solution) සෙවීම: දකුණු පස 0 ට සමාන කර කලින් පාඩමේ ක්‍රමයටම මූල සොයා ලියන උත්තරයයි.

## 1. Undetermined Coefficients (අනිශ්චිත සංගුණක ක්‍රමය)

**"Dummy-Proof" Concept:**
සමීකරණයේ දකුණු පැත්තේ $f(x)$ කියලා මොකක්හරි ශ්‍රිතයක් තියෙනවා (උදා: $e^{2x}$, $\sin x$, $x^2$). අපි කරන්නේ ඒ $f(x)$ දිහා බලලා, අපේ Particular Solution එක ($y_p$) මොන වගේ හැඩයකින් තියෙයිද කියලා "අනුමාන කරන" (Guess) එකයි. ඊට පස්සේ ඒ අනුමාන කරපු එක මුල් සමීකරණයට ආදේශ කරලා, ඒකේ තියෙන අකුරු (A, B, C) වල අගයන් හොයනවා.

**How to Guess $y_p$ (අනුමාන කරන හැටි):**
*   $f(x) = 5e^{4x}$ වගේ ආවොත් $\implies$ **$y_p = A e^{4x}$**
*   $f(x) = 3\sin(2x)$ හෝ $2\cos(2x)$ ආවොත් $\implies$ **$y_p = A \cos(2x) + B \sin(2x)$** (මතක තියාගන්න, ප්‍රශ්නේ $\sin$ විතරක් තිබ්බත් අනුමාන කරද්දී දෙකම ලියන්න ඕනේ!)
*   $f(x) = 4x^2 - 3x$ වගේ බහුපදයක් ආවොත් $\implies$ **$y_p = Ax^2 + Bx + C$**

> [!CAUTION]
> **The Modification Rule (අතිශයින්ම වැදගත් Exam Trap එකක්):**
> ඔයා අනුමාන කරපු $y_p$ එකේ තියෙන පදයක්, දැනටමත් $y_c$ එක ඇතුලේ තියෙනවා නම්, ඔයාගේ අනුමානය වැරදියි! ඒ වෙලාවට ඔයාගේ $y_p$ එක අනිවාර්යයෙන්ම $x$ වලින් ගුණ කරන්න ඕනේ. තාමත් සමාන නම් $x^2$ වලින් ගුණ කරන්න ඕනේ.

### ✍️ Step-by-Step Worked Example

**Question:** Solve $y'' - 5y' + 6y = 4e^{2x}$

*   **Step 1: $y_c$ සෙවීම (දකුණු පස 0 කර)**
    $r^2 - 5r + 6 = 0 \implies (r-2)(r-3) = 0 \implies r = 2, 3$.
    **$y_c = c_1 e^{2x} + c_2 e^{3x}$**

*   **Step 2: $y_p$ අනුමාන කිරීම (Guessing)**
    දකුණු පස තියෙන්නේ $4e^{2x}$. ඒ අනුව අපි අනුමාන කරන්නේ $y_p = A e^{2x}$ කියලයි.
    *නමුත් පොඩ්ඩක් ඉන්න!* අපේ $y_c$ එක ඇතුලෙත් $e^{2x}$ පදයක් තියෙනවා නේද? ($c_1 e^{2x}$).
    ඒ නිසා අපේ අනුමානය $x$ වලින් ගුණ කරන්න වෙනවා (Modification Rule).
    නිවැරදි අනුමානය: **$y_p = A x e^{2x}$**
    
*   **Step 3: අවකලනය කර ආදේශ කිරීම**
    $y_p = A x e^{2x}$ (මෙය Product Rule එකෙන් අවකලනය කරන්න)
    $y_p' = A(e^{2x} + 2x e^{2x})$
    $y_p'' = A(2e^{2x} + 2e^{2x} + 4x e^{2x}) = A(4e^{2x} + 4x e^{2x})$
    
    මේවා මුල් සමීකරණයට ආදේශ කරමු ($y'' - 5y' + 6y = 4e^{2x}$):
    $[4A e^{2x} + 4Ax e^{2x}] - 5[A e^{2x} + 2Ax e^{2x}] + 6[Ax e^{2x}] = 4e^{2x}$
    
    දැන් $e^{2x}$ පද සහ $x e^{2x}$ පද වෙන් කරලා සුළු කරමු:
    $e^{2x} (4A - 5A) + x e^{2x} (4A - 10A + 6A) = 4e^{2x}$
    $e^{2x} (-A) + x e^{2x} (0) = 4e^{2x}$
    $-A = 4 \implies A = -4$
    
*   **Step 4: අවසාන පිළිතුර ලිවීම**
    $y_p = -4x e^{2x}$.
    $y = y_c + y_p \implies$ **$y = c_1 e^{2x} + c_2 e^{3x} - 4x e^{2x}$**

## 2. Variation of Parameters (පරාමිති විචලනය)

**"Dummy-Proof" Concept:**
අර කලින් කරපු අනුමාන කිරීමේ ක්‍රමය කරන්න බැරි ශ්‍රිත දකුණු පැත්තේ ආවොත් (උදා: $\sec x, \tan x, \ln x, \frac{1}{x}$), අපි මේ ක්‍රමය පාවිච්චි කරනවා. මේකෙදි අනුමාන කරන්නේ නෑ, කෙලින්ම සූත්‍රයකට දාලා අනුකලනය කරනවා.

**Solving Steps (පියවර):**
1.  $y_c = c_1 y_1 + c_2 y_2$ සොයාගෙන $y_1$ සහ $y_2$ හඳුනාගන්න.
2.  ඒවායේ Wronskian එක ($W$) ගණනය කරන්න.
3.  සමීකරණය $y'' + \dots = f(x)$ හැඩයට ගෙන (එනම් $y''$ ළඟ 1 තියාගෙන) දකුණු පස $f(x)$ ලෙස ගන්න.
4.  සූත්‍රය: **$y_p = -y_1 \int \frac{y_2 f(x)}{W} dx + y_2 \int \frac{y_1 f(x)}{W} dx$**

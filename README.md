## 📌 About This Repository

This is the official centralized repository for the **Batch Kuppi Initiative**. Our primary goal is to collaboratively study, share resources, and ensure a **100% Pass Rate** for upcoming final exams, paving the way for our Special Degree opportunities.

What makes this project truly special is that it is a **100% static site hosted entirely on GitHub Pages**, yet it acts like a fully dynamic, database-driven Learning Management System (LMS) with advanced Artificial Intelligence capabilities!

## 🌐 The Kuppi Web Portal

We have built a custom, fully responsive Web Portal to view notes, PDFs, recordings, and external links beautifully without downloading anything. It works perfectly on Mobiles, Tablets, Laptops, and Smart TVs!

👉 **[Click Here to Visit the Live Portal](https://pathum-official.github.io/Batch-Kuppi-Initiative/)**

## ✨ Groundbreaking Features

### 🤖 The AI Teacher (Batch Kuppi Agent)
We have integrated a highly intelligent **AI Agent** directly into the portal. This is not just a standard chatbot; it has **Superpowers**:
- **Agentic RAG & Semantic Search:** The AI can autonomously search through the entire repository's files, notes, and past papers instantly. If you ask, *"What past papers are available?"*, it will scan the system and return direct, clickable links!
- **Context-Aware Assistance:** You can attach notes directly from the portal to the AI chat to ask questions, summarize content, or debug code.
- **Dynamic Content Generation:** The AI can generate temporary interactive web pages on the fly to explain complex concepts, render code blocks, or embed videos!

### ⚡ No Backend, No Database!
This entire ecosystem runs purely on the Frontend using Vanilla JavaScript. All "backend-like" operations, routing, advanced semantic search functionality, and AI orchestration are executed natively in the browser.

### 🔗 Smart URL Routing
You can link any resource directly by adding parameters to the URL. The system automatically handles complex folder paths, spaces, and formatting!
- **📝 Markdown Notes:** `?note=ICT1022/01_Instruction_Format`
- **📕 PDFs:** `?pdf=ICT1011/Slides/Lecture1.pdf`
- **🎬 Local Videos:** `?video=Recordings/Zoom_Day1.mp4`
- **🖼️ Images:** `?img=Maths/Diagrams/logic.png`
- **▶️ YouTube Videos:** `?yt=dQw4w9WgXcQ` *(Just provide the Video ID)*

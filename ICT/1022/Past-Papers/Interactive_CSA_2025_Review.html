Question 1(i)

Modified Harvard Architecture

"Modern processors often use a modified Harvard architecture instead of a pure Von Neumann or Harvard architecture."

නවීන ප්‍රොසෙසර වල ගොඩක් වෙලාවට පාවිච්චි කරන්නේ පිරිසිදු වොන් නියුමාන් හෝ හාවඩ් ආකෘතිය වෙනුවට මොඩිෆයිඩ් හාවඩ් ආකෘතියක් කියලයි මේ මුලින්ම කියන්නේ.

Part (a)

හරි, අපි පළවෙනි ප්‍රශ්නයෙන් පටන් ගමු! මේක පරිගණක වාස්තු විද්‍යාවෙ එන මූලිකම තියරි ප්‍රශ්නයක්.

"Briefly explain what a modified Harvard architecture is, and how it differs from pure Von Neumann and Harvard models."

මේ ප්‍රශ්නයෙන් අහන්නේ මොඩිෆයිඩ් හාවඩ් කියන්නේ මොකක්ද, ඒක අනිත් ආකෘති දෙකෙන් වෙනස් වෙන්නේ කොහොමද කියලා කෙටියෙන් පැහැදිලි කරන්න කියලයි.

Exam Answer:

Modified Harvard Architecture: It is a hybrid model that uses a single, unified main memory for both data and instructions externally (like Von Neumann).

But separates them internally within the CPU using distinct, separate L1 caches for data and instructions (like Harvard).

මේ ලියපු එකේ තේරුම තමයි, මොඩිෆයිඩ් හාවඩ් කියන්නේ දෙමුහුන් ආකෘතියක්. එළියෙන් තියෙන්නේ වොන් නියුමාන් වගේ එකම ප්‍රධාන මතකයක් විතරයි.

හැබැයි ප්‍රොසෙසරය ඇතුළෙ තියෙන එල් වන් කෑෂ් එක, දත්ත සහ උපදෙස් විදිහට කෑලි දෙකකට වෙන් කරලයි තියෙන්නේ. හරියට පියෝ හාවඩ් වගේ.

Differences:

1. Pure Von Neumann: Uses a single unified memory and a single bus for both data and instructions internally and externally, leading to a bottleneck.

වොන් නියුමාන් වල ඇතුළෙත් එළියෙත් තියෙන්නේ එකම මතකයක් සහ එකම බස් එකක්. ඒ නිසා දත්තයි උපදෙස් දෙකම එකපාර ගන්න බෑ. පෝලිමේ ඉන්න ඕනේ. මේකට තමයි වොන් නියුමාන් බොට්ල්නෙක් කියන්නේ.

2. Pure Harvard: Strictly uses two physically separate main memory modules and buses for data and instructions, which is highly expensive and complex.

පිරිසිදු හාවඩ් වල සම්පූර්ණයෙන්ම වෙනස් භෞතික මතකයන් දෙකක් තියෙනවා. ඒක වේගවත් වුණාට හදන්න අමාරුයි වගේම වියදමත් ගොඩක් වැඩියි.

Conclusion: Modified Harvard merges the best of both by keeping main memory unified while dividing internal cache memory.

ඒකයි මොඩිෆයිඩ් හාවඩ් හැදුවේ. එළියෙන් එක මතකයක් තියලා වියදම අඩු කළා. ඇතුළෙන් කෑෂ් දෙකක් තියලා වේගය වැඩි කළා.

Quick Quiz 1: What is the key feature of a Modified Harvard Architecture?

අපි බලමු මේ කොටස ඔයාට තේරුණාද කියලා. මොඩිෆයිඩ් හාවඩ් වල ප්‍රධානම ලක්ෂණය මොකක්ද? නිවැරදි උත්තරය පහළින් තෝරන්න.

Correct! මොඩිෆයිඩ් හාවඩ් වල එළියෙන් එක මතකයක් තිබුණත්, ප්‍රොසෙසරය ඇතුළේ L1 Cache එක දත්ත වලටයි උපදෙස් වලටයි දෙකකට කඩලා තියෙනවා.

Part (b)

හරි, දැන් අපි දෙවෙනි අනු කොටසට යමු. මේකෙදි අහන්නේ Modified Harvard වල තියෙන ප්‍රධාන වාසි ගැන.

"Discuss two key advantages of the modified Harvard architecture over the pure Von Neumann architecture."

පිරිසිදු වොන් නියුමාන් ආකෘතියට වඩා මොඩිෆයිඩ් හාවඩ් වල තියෙන ප්‍රධාන වාසි දෙකක් ගැන සාකච්ඡා කරන්න කියලයි මේ දෙවෙනි කොටසින් අහන්නේ.

Exam Answer:

  • 1. Concurrency & High Throughput: Because there are separate internal caches and buses for data and instructions, the CPU can fetch an instruction and read/write data simultaneously in the exact same clock cycle without any stalls.

    මේකෙ පළවෙනි වාසිය තමයි වේගය. ඇතුළේ කෑෂ් දෙකක් තියෙන නිසා, ප්‍රොසෙසරයට එකම වෙලාවේ උපදෙසකුයි දත්තයකුයි දෙකම ගන්න පුළුවන්. පෝලිමේ ඉන්න ඕනේ නෑ.

  • 2. Elimination of the Von Neumann Bottleneck: Instructions can be fetched from the L1 Instruction Cache over a dedicated internal bus while data is handled over another, removing the resource conflict of a single shared memory bus.

    දෙවෙනි වාසිය තමයි වොන් නියුමාන් බොට්ල්නෙක් එක නැතිවෙන එක. උපදෙස් සහ දත්ත ගේන්න ඇතුළේ වෙන වෙනම පාරවල් දෙකක් තියෙන නිසා, එකම පාරේ තදබදයක් ඇතිවෙන්නේ නෑ.

  • 2 Marks for each valid advantage with proper explanation.

Quick Quiz 2: How does Modified Harvard eliminate the Von Neumann bottleneck?

මේ කොටසෙන් ප්‍රශ්නයක්. මොඩිෆයිඩ් හාවඩ් වලින් වොන් නියුමාන් බොට්ල්නෙක් එක නැති කරන්නේ කොහොමද? නිවැරදි උත්තරය පහළින් තෝරන්න.

Correct! ඇතුළේ වෙන වෙනම පාරවල් දෙකක් තියෙන නිසා, එකම බස් එකේ දත්තයි උපදෙස් දෙකම යන්න තියෙන තදබදය නැතිවෙනවා.

Part (c)

ඊළඟට අපි තුන්වෙනි අනු කොටස බලමු. මේකෙදි කෑෂ් මතකය කොහොමද උදව් වෙන්නේ කියලා අහන්නේ.

"Explain the role of L1 Instruction and Data caches in improving the overall throughput of a modified Harvard architecture processor."

මොඩිෆයිඩ් හාවඩ් ආකෘතියේ ප්‍රොසෙසරයක වේගය වැඩි කරන්න L1 Instruction Cache එකයි Data Cache එකයි උදව් වෙන්නේ කොහොමද කියලා පැහැදිලි කරන්න කියලයි මේ කොටසින් අහන්නේ.

Exam Answer:

The L1 Instruction Cache stores frequently executed code, while the L1 Data Cache stores variables and operational data.

ප්‍රොසෙසරයක් ඇතුළේ තියෙන L1 කෑෂ් එක කොටස් දෙකකට කඩලා තියෙනවා. Instruction cache එකේ තියෙන්නේ කෝඩ් එක. Data cache එකේ තියෙන්නේ වේරියබල්ස්.

By providing separate physical pathways, the CPU can read an instruction and read/write data in the exact same clock cycle without stalling.

මේ විදිහට පාරවල් දෙකක් තියෙන නිසා, ප්‍රොසෙසරයට පුළුවන් එකම වෙලාවෙ කෝඩ් එකකුයි දත්තයකුයි ගන්න. මොහොතක්වත් නිකන් ඉන්න ඕනේ නෑ.

This parallel fetching drastically increases the overall instruction throughput and processor efficiency.

මේ නිසා ප්‍රොසෙසරයේ කාර්යක්ෂමතාවය සහ වේගය අතිශයින්ම වැඩි වෙනවා.

Model Question 1

Discuss the primary reason for the "Von Neumann Bottleneck" and explain how cache memory helps mitigate it.

වොන් නියුමාන් බොට්ල්නෙක් එකට ප්‍රධානම හේතුව සහ කෑෂ් මෙමරි එකෙන් ඒක විසඳන හැටි සාකච්ඡා කරන්න කියලයි මේ අහන්නේ.

Exam Answer:

The bottleneck occurs because instructions and data share a single bus and memory, causing the faster CPU to wait. Cache memory (SRAM) mitigates this by sitting between the CPU and Main Memory, storing frequently used instructions/data, reducing access time and bus contention.

මෙතනදි අහන්නේ වොන් නියුමාන් බොට්ල්නෙක් එකට හේතුව සහ කෑෂ් එකෙන් ඒක විසඳන්නේ කොහොමද කියන එකයි. දත්තයි උපදෙස් දෙකම එකම පාරක (Bus එකක) යන නිසා තමයි තදබදය එන්නේ. කෑෂ් මෙමරි එකක් ප්‍රොසෙසරය ළඟින්ම තියලා මේ ප්‍රශ්නේ විසඳන්න පුළුවන්.

What type of memory is typically used for Cache to mitigate the bottleneck?

මේ ප්‍රශ්නයට උත්තරය පහළින් තෝරන්න.

Correct! Cache memory වලට පාවිච්චි කරන්නේ SRAM. ඒක ගොඩක් වේගවත් වගේම වියදමත් වැඩියි. Main memory එකට තමයි DRAM පාවිච්චි කරන්නේ.

Model Question 2 (Design Decision)

A modern smartphone processor requires high performance and low power consumption. Why would a designer choose a Modified Harvard architecture over a Pure Harvard architecture?

ස්මාර්ට්ෆෝන් එකකට, Pure Harvard වෙනුවට Modified Harvard තෝරගන්නේ ඇයි කියලයි මේ ප්‍රශ්නයෙන් අහන්නේ.

Exam Answer:

Pure Harvard requires two physically separate memory modules and buses, increasing chip size, complexity, and cost. Modified Harvard offers the speed benefits of separate L1 caches while allowing the use of a single, cheaper main memory, making it ideal for mobile devices where space and cost are critical.

ස්මාර්ට් ෆෝන් එකකට Pure Harvard ගැලපෙන්නේ නෑ. මොකද ඒකට මතකයන් දෙකක් ඕනේ නිසා ෆෝන් එක ඇතුළේ ඉඩ යනවා, ඒ වගේම වියදමත් වැඩියි. ඒ නිසා තමයි Modified Harvard පාවිච්චි කරන්නේ.

What is the main disadvantage of Pure Harvard architecture for mobile devices?

මේ ප්‍රශ්නයට උත්තරය පහළින් තෝරන්න.

Correct! Pure Harvard එක වේගවත් වුණාට හදන්න ගොඩක් වියදම් යනවා වගේම ඉඩත් ගොඩක් ගන්නවා.

Model Question 3 (Deep Dive)

Explain the difference between L1 Instruction Cache and L1 Data Cache in a Modified Harvard Architecture.

Modified Harvard ආකෘතියේ L1 Instruction Cache එකයි, Data Cache එකයි අතර තියෙන වෙනස මොකක්ද කියලා තමයි මේ අහන්නේ.

Exam Answer:

L1 Instruction Cache stores executable code, while L1 Data Cache stores variables and data used by the program. They are separated so the CPU can fetch an instruction and read/write data simultaneously in the same clock cycle.

L1 Cache එක ඇතුළේ කෑලි දෙකක් තියෙනවා. Instruction cache එකේ තියෙන්නේ ප්‍රෝග්‍රෑම් එකේ කෝඩ් එක. Data cache එකේ තියෙන්නේ අපි පාවිච්චි කරන වේරියබල්ස්. මේ දෙක වෙන් කළාම ප්‍රොසෙසරයට එකම වෙලාවේ කෝඩ් එකකුයි දත්තයකුයි ගන්න පුළුවන්.

What does the L1 Instruction cache exclusively store?

මේ ප්‍රශ්නයට උත්තරය පහළින් තෝරන්න.

Correct! Instruction cache එකේ තියෙන්නේ නිතරම පාවිච්චි වෙන Executable Code එක විතරයි.

Model Question 4

What happens if a CPU with a Modified Harvard Architecture cannot find the required data in the L1 Data Cache?

L1 Cache එකේ අවශ්‍ය දත්තය තිබුණේ නැත්නම් ප්‍රොසෙසරය ඊළඟට මොකද කරන්නේ කියලයි මේ ප්‍රශ්නයෙන් අහන්නේ.

Exam Answer:

A "Cache Miss" occurs. The CPU must then fetch the data from the L2/L3 unified cache. If not found there, it fetches from the Main Memory (RAM) over the unified system bus, which takes significantly more clock cycles.

ප්‍රොසෙසරයට ඕනේ දත්තය L1 Cache එකේ තිබ්බේ නැත්නම් ඒකට Cache Miss එකක් කියලා කියනවා. එතකොට ප්‍රොසෙසරය ඊළඟට බලන්නේ L2, L3 වල. එතනත් නැත්නම් අන්තිමට යන්නේ Main Memory එකට.

What is it called when the CPU cannot find the data in the cache?

Correct! දත්තය තිබ්බොත් ඒකට Cache Hit එකක් කියනවා. දත්තය තිබ්බෙ නැත්නම් Cache Miss එකක් කියනවා.

Arithmetic Logic Unit (ALU)

Explain the functions of the Arithmetic Logic Unit (ALU) in detail. Include at least four operations it can perform.

දැන් අපි බලමු Arithmetic Logic Unit, එහෙමත් නැත්නම් ALU කියන එකේ කාර්යයන් මොනවද කියලා. මේකෙන් කරන ප්‍රධාන මෙහෙයුම් 4ක් අපිට ලියන්න වෙනවා.

Function: The ALU is the computational heart of the CPU. It is purely responsible for executing all mathematical and logical data processing operations as dictated by the Control Unit.

It takes raw inputs from registers, processes them through combinational logic circuits, and outputs the result back to a register, while also updating status flags (like Zero, Carry, or Negative).

ALU එක කියන්නේ CPU එකේ ගණිතමය සහ තාර්කික වැඩ සේරම කරන ප්‍රධානම තැන. Control Unit එකෙන් දෙන උපදෙස් වලට අනුව තමයි මෙයා වැඩ කරන්නේ. Registers වලින් දත්ත අරගෙන, ඒවා එකතු කිරීම්, අඩු කිරීම් වගේ දේවල් කරලා ආයෙත් Register එකකටම ප්‍රතිඵලය යවනවා.

Four Operations

  • 1. Arithmetic Addition (ADD): Adds two integer values.
  • 2. Arithmetic Subtraction (SUB): Subtracts one value from another using 2's complement logic.
  • 3. Logical AND: Performs a bitwise AND operation for masking bits.
  • 4. Logical Shift (LSL/LSR): Shifts bits left or right, effectively multiplying or dividing by powers of 2.

එයාට කරන්න පුළුවන් ප්‍රධාන වැඩ 4ක් තමයි: එක, Arithmetic Addition හෙවත් එකතු කිරීම. දෙක, Arithmetic Subtraction හෙවත් අඩු කිරීම. තුන, Logical AND කිරීම. හතර, Logical Shift හෙවත් බිට්ස් එහාට මෙහාට කරන එක.

Model Question 1

How does the ALU use the subtraction operation to determine if two values are equal?

සමාන අගයන් දෙකක් සංසන්දනය කරන්න ALU එක අඩු කිරීම පාවිච්චි කරන්නේ කොහොමද කියලයි මේ අහන්නේ.

Exam Answer:

The ALU performs a subtraction (A - B). If the two values are equal, the result is exactly zero. The ALU then sets the 'Zero Flag' in the CPU Status Register to 1. The Control Unit reads this flag to make logical decisions.

එක අගයකින් අනිත් අගය අඩු කළාම උත්තරේ බිංදුව නම්, ALU එක Status Register එකේ තියෙන Zero Flag එක 1 කරනවා. ඒකෙන් Control Unit එකට තේරෙනවා සංඛ්‍යා දෙක සමානයි කියලා.

What flag does the ALU set if the result of a subtraction is zero?

මේ ප්‍රශ්නයට උත්තරය පහළින් තෝරන්න.

Correct! අඩු කිරීමකින් පස්සේ උත්තරේ 0 නම් Zero Flag එක 1 වෙනවා. Carry Flag එක 1 වෙන්නේ එකතු කිරීමකදී (addition) අගය පිටාර ගියොත් විතරයි.

Model Question 2

In modern ALUs, why is the 'Logical AND' operation frequently used by programmers?

Logical AND එක වැඩියෙන්ම පාවිච්චි වෙන්නේ ඇයි කියලයි මේ ප්‍රශ්නයෙන් අහන්නේ.

Exam Answer:

Logical AND is commonly used for 'Bit Masking'. It allows programmers to isolate or extract specific bits from a binary number by AND-ing it with a mask.

Logical AND එක වැඩියෙන්ම පාවිච්චි වෙන්නේ Bit Masking කියන වැඩේට. ඒ කියන්නේ අපිට ඕනේ නැති බිට්ස් බිංදුව කරලා, අපිට අවශ්‍ය බිට්ස් ටික විතරක් පෙරලා ගන්න මේක පාවිච්චි කරනවා.

What is the primary practical use of the Logical AND operation?

මේ ප්‍රශ්නයට උත්තරය පහළින් තෝරන්න.

Correct! Logical AND පාවිච්චි කරන්නේ Bit Masking (අනවශ්‍ය බිට්ස් මකා දැමීම) සඳහා. එකතු කිරීම් වලට පාවිච්චි කරන්නේ ADD operation එක.

Model Question 3

How does the ALU contribute to the execution of a 'Branch if Negative' (BLT/BNE) instruction?

අගයක් සෘණ (Negative) ද කියලා හොයන්න ALU එක උදව් කරන්නේ කොහොමද කියලා මේ අහන්නේ.

Exam Answer:

The ALU performs a subtraction between two operands. If the result is less than zero, the ALU sets the 'Negative Flag' (or Sign Flag) in the Status Register to 1. The Control Unit then uses this flag to execute the branch.

යම්කිසි අගයක් සෘණ අගයක්ද කියලා බලන්න ALU එක අඩු කිරීමක් කරනවා. උත්තරේ සෘණ නම්, ඒකෙන් 'Negative Flag' එක 1 කරනවා. Control Unit එක මේක බලලා තමයි ඊළඟට යන්න ඕනේ කොහාටද කියලා තීරණය කරන්නේ.

What flag is set by the ALU if the result of an arithmetic operation is less than zero?

මේ ප්‍රශ්නයට උත්තරය පහළින් තෝරන්න.

Correct! උත්තරය බිංදුවට වඩා අඩු නම් (සෘණ) Negative Flag එක 1 වෙනවා. Overflow Flag එක පාවිච්චි කරන්නේ අගය Register එකේ සීමාව පැනලා ගියොත් විතරයි.

Logical Shift operations are implemented at the hardware level using simple combinational logic, which allows them to execute in a single clock cycle. Standard multiplication requires complex circuitry and multiple clock cycles.

Logical Shift කියන්නේ හරිම සරල හාඩ්වෙයාර් ක්‍රියාවලියක්. ඒක එක Clock Cycle එකකින්ම ඉවර කරන්න පුළුවන්. හැබැයි සාමාන්‍ය ගුණ කිරීමක් කරන්න ඊට වඩා ගොඩක් වෙලාව යනවා.

Compare assembly language and high-level language in terms of readability, portability, and execution.

Illustrate the instruction execution cycle of a computer with the help of a diagram, and briefly explain the role of the PC, IR, MAR, and MDR.

Instruction Execution Cycle

1. Fetch Instruction
2. Decode Instruction
3. Fetch Operands
4. Execute Instruction
5. Store Result

චක්‍රය පටන් ගන්නේ Fetch එකෙන්, ඊළඟට Decode, ඊළඟට දත්ත ගන්නවා (Fetch operands), ඊළඟට Execute කරනවා, අන්තිමට Result එක Store කරලා ආපහු මුලට යනවා.

Role of Key CPU Registers

1. PC (Program Counter)

Holds the specific memory address of the next instruction to be fetched from memory.

ඊළඟට ක්‍රියාත්මක කරන්න තියෙන උපදෙසේ ලිපිනය තමයි PC එකේ තියෙන්නේ.

2. IR (Instruction Register)

Holds the actual, current instruction that has just been fetched from memory and is actively being decoded.

දැනට අරගෙන තියෙන, මේ මොහොතේ Decode වෙන උපදෙස තියෙන්නේ IR එකේ.

3. MAR (Memory Address Register)

Connected to the Address Bus. It holds the memory address of the data or instruction that the CPU wants to read from or write to.

CPU එකට කියවන්න හරි ලියන්න හරි ඕනේ කරන තැනේ Memory Address එක තියෙන්නේ මේකේ.

4. MDR (Memory Data Register)

Connected to the Data Bus. It acts as a buffer, holding the actual data that was just read from memory, or data about to be written.

කියවපු දත්තය හරි, ලියන්න යන දත්තය හරි තාවකාලිකව තියාගන්න buffer එකක් විදිහට MDR එක ක්‍රියා කරනවා.

University Level Model Questions

Model Question 1

Why is the Program Counter (PC) updated immediately after the instruction is fetched?

Exam Answer:

Updating the PC immediately allows modern processors to implement 'Pipelining'. While the current instruction is being decoded or executed, the processor can already start fetching the next instruction from the newly updated PC address.

What major processor feature is enabled by updating the PC early?
Correct! Pipelining allows overlapping execution stages.

Model Question 2

What would happen if the MAR and MDR were replaced by a single, shared register?

Exam Answer:

It would cause a structural conflict. A single register cannot hold the address and receive the incoming data at the exact same time without overwriting the address before the read is complete.

Why can't MAR and MDR be combined?
Correct! We need separate registers for the address and the incoming data.

Model Question 3

Discuss the role of the System Clock in relation to the Instruction Execution Cycle.

Exam Answer:

The System Clock provides a continuous sequence of electrical pulses that synchronize all components. Each stage of the instruction cycle (Fetch, Decode, Execute) is triggered by these clock pulses, ensuring that data is safely transferred between registers without race conditions.

What ensures all stages of the instruction cycle happen in a synchronized manner?
Correct! The Clock keeps all CPU parts moving together perfectly.

Model Question 4

How does a branch instruction (like JUMP) affect the normal execution cycle?

Exam Answer:

Normally, the PC auto-increments to the next sequential address. A branch instruction alters this by forcing the ALU to calculate a new target address, which is then forcibly written into the PC, disrupting the sequential flow.

What register gets forcibly overwritten when a JUMP instruction is executed?

If a memory location is accessed now, it is highly likely to be accessed again very soon. Cache exploits this by keeping recently accessed data stored.

If a memory location is accessed, nearby memory locations will likely be accessed soon. Cache exploits this by fetching entire Blocks of data from RAM at once.

Correct! Spatial locality assumes nearby data will be needed.

Step 1: Find 2's complement of B (to get -B)

  • B = 000111
  • 1's complement of B (invert bits) = 111000
  • Add 1 to get 2's complement = 111000 + 1 = 111001
  • So, -B = 111001

Step 2: Add A and (-B)

  001101   (This is A)
+ 111001   (This is -B)
---------
1 000110
---------

Discard the carry out bit '1'.

Final Result: 000110

පරිගණකයකට අඩු කරන්න බෑ, ඒ නිසා A - B කියන එක A + (-B) විදිහට හදාගන්නවා. මුලින්ම B වල අගය කණපිට හරවලා එකක් එකතු කරලා (2's complement) -B හොයාගන්නවා. ඊට පස්සේ ඒක A ට එකතු කරනවා. අන්තිමට එන Carry එක අතාරින්න ඕනේ.

In Immediate Addressing, the actual data value is embedded directly inside the instruction (no memory fetch needed). In Base Addressing, an address must first be calculated, and then a memory fetch is performed to get the data.

Which addressing mode requires ZERO fetches from Main Memory to get the operand?
Correct! Immediate data is right inside the instruction itself.

Model Question 3

If the instruction uses a 16-bit signed displacement field, what is the maximum positive offset possible?

Exam Answer:

A 16-bit signed 2's complement number can represent values from -(2^15) to +(2^15 - 1). Therefore, the maximum positive offset is +32767 bytes.

What is the max positive value for a 16-bit signed offset?
Correct! Since it's signed, one bit is used for the sign, leaving 15 bits for the magnitude ((2^15)-1).

Model Question 4

What happens if the calculated Effective Address exceeds the total physical memory capacity?

Exam Answer:

The Memory Management Unit (MMU) will detect that the address is out of bounds and trigger a hardware exception, known as a Segmentation Fault or Memory Access Violation, typically crashing the program.

What error occurs when an EA points to memory that doesn't exist?
Correct! Trying to access invalid memory results in a SegFault.

Question 3(iii)

Load-Store Architecture & Pipelining

MIPS32 follows a load-store architecture. Explain why this design choice simplifies pipelining.

මේකෙන් අහන්නේ MIPS32 වල තියෙන Load-Store Architecture එක නිසා Pipelining කරන එක ලේසි වෙන්නේ ඇයි කියලයි.

What is a Load-Store Architecture?

In a Load-Store architecture (RISC), arithmetic and logic operations (like ADD, SUB) can only be performed on values already inside CPU registers. They are strictly forbidden from directly interacting with main memory.

NOT ALLOWED: ADD R1, [Memory_Address]
ALLOWED: LOAD R2, [Memory_Address] ADD R1, R2

Load-Store කියන්නේ Memory එකත් එක්ක ගනුදෙනු කරන්න පුළුවන් LOAD සහ STORE කියන විධාන දෙකට විතරයි. ADD වගේ ගණන් හදන විධාන වලට Memory එකට යන්න බෑ, ඒවට පාවිච්චි කරන්න පුළුවන් Registers විතරයි.

Why it Simplifies Pipelining

1. Uniform Length

It forces all instructions to have a highly uniform, predictable length (32 bits) and execution time.

හැම උපදෙසක්ම එකම දිගකින් යුක්ත නිසා, Fetch කරන එක ලේසියි.

2. Balanced Pipeline Stages

Because ALU instructions don't wait for slow memory reads, the pipeline stages (IF, ID, EX, MEM, WB) become perfectly balanced. The "MEM" stage is simply bypassed for ALU ops.

මැදදි Memory එකට යන්න ගියොත් පෝලිම හිරවෙනවා. මේ ක්‍රමයේදී ඒක වෙන්නේ නැති නිසා Pipeline එක smoothly දුවනවා.

Quick Quiz: In a Load-Store architecture, can an ADD instruction fetch its operands directly from RAM?
Correct! ADD can only operate on Registers. You must LOAD the data first.

University Level Model Questions

Model Question 1

What is a Register-Memory architecture (CISC) and how does it contrast with Load-Store (RISC)?

Exam Answer:

CISC allows arithmetic operations to fetch operands directly from memory (e.g. ADD R1, [Memory_Address]), which complicates hardware and pipelining. RISC strictly separates memory access from arithmetic.

Which architecture allows arithmetic instructions to access memory directly?
Correct! CISC architectures like x86 allow this, making them more complex.

Model Question 2

How does a Load-Store architecture impact the number of registers required in a CPU?

Exam Answer:

It requires a significantly larger number of General Purpose Registers (GPRs) because all intermediate data must be temporarily stored in registers before any computation can happen.

Load-Store architectures typically have:
Correct! Since you can't compute on memory, you need lots of registers to hold data.

Model Question 3

In a classic 5-stage pipeline, what does an ADD instruction do during the MEM (Memory) stage?

Exam Answer:

It simply does nothing (idles or bypasses). Since ADD cannot touch memory in a Load-Store architecture, the MEM stage is skipped, ensuring the pipeline timing remains perfectly uniform without stalling.

What happens during the MEM stage for an arithmetic instruction in RISC?
Correct! Arithmetic instructions skip the Memory stage entirely.

Model Question 4

Why are uniform instruction lengths crucial for a smooth pipeline?

Exam Answer:

If instructions were different lengths, the Instruction Fetch (IF) and Decode (ID) stages wouldn't know exactly how many bytes to grab per cycle, causing bottlenecks and stalls. Uniform lengths guarantee exactly one instruction flows per clock cycle.

What guarantees that the Fetch stage grabs exactly one complete instruction per cycle?
Correct! Fixed length means the CPU always knows exactly how much to fetch.

MIPS32 Instruction Encoding

Consider: add $t1, $s1, $s2, lw $t2, 100($s3), j 40000. Identify formats, show fields, and translate to machine code.

Assembly කෝඩ් 3ක් දීලා තියෙනවා. මේවායේ වර්ගය (R, I, J) හොයාගෙන, Format එක ලියලා, 0 සහ 1 (Machine Code) වලට හරවන්නයි තියෙන්නේ.

1. Identifying Types

add $t1, $s1, $s2
R-type (Register)
lw $t2, 100($s3)
I-type (Immediate)
j 40000
J-type (Jump)

2. Instruction Encoding Fields

R-type (32 bits): [opcode (6)] | [rs (5)] | [rt (5)] | [rd (5)] | [shamt (5)] | [funct (6)]

I-type (32 bits): [opcode (6)] | [rs (5)] | [rt (5)] | [immediate (16)]

J-type (32 bits): [opcode (6)] | [target address (26)]

3. Translating to Machine Code

add $t1, $s1, $s2
(rs=$s1=17, rt=$s2=18, rd=$t1=9. Opcode=0, Funct=32)
000000 10001 10010 01001 00000 100000
lw $t2, 100($s3)
(rs=$s3=19, rt=$t2=10, imm=100. Opcode=35)
100011 10011 01010 0000000001100100
j 40000
(target=10000 (after /4). Opcode=2)
000010 000000000010011100010000

University Level Model Questions

Model Question 1

In the R-type format, what is the specific purpose of the 'shamt' field?

Exam Answer:

The 'shamt' (shift amount) field specifies how many bits to shift the value during bitwise shift instructions (like `sll` or `srl`). For non-shift instructions like ADD, it is unused and strictly set to 00000.

What value does 'shamt' hold when executing an ADD instruction?
Correct! ADD does not shift bits, so shift amount is zero.

Model Question 2

Why does the J-type instruction only have 26 bits for the address when physical memory addresses are 32 bits?

Exam Answer:

MIPS instructions are word-aligned (multiples of 4 bytes), so the lowest 2 bits of any address are always 00 and are omitted to save space. The highest 4 bits are taken from the current Program Counter (PC+4).

What does the CPU automatically append to the end of the 26-bit jump target to make it a real address?
Correct! Appending 00 multiplies the address by 4 automatically.

Model Question 3

In the I-type instruction, what is the fundamental limitation of the immediate value?

Exam Answer:

The immediate field is only 16 bits wide, meaning it can only represent constant values from -32,768 to +32,767. If a larger constant is required, the programmer must use multiple instructions like 'lui' (Load Upper Immediate).

How many bits are allocated for the constant (immediate) in I-type instructions?
Correct! 16 bits for data, the rest are for opcode and registers.

Model Question 4

What differentiates the `opcode` field from the `funct` field in R-type instructions?

Exam Answer:

For all R-type instructions, the 6-bit `opcode` is universally 000000. The processor then looks at the 6-bit `funct` field at the very end of the instruction to figure out exactly which math operation (add, sub, or, etc.) to perform.

If the opcode is 000000, where does the CPU look to know if it should add or subtract?
Correct! The 'funct' field determines the exact R-type operation.

# 📚 L12: Input-Output Systems

මෙම පාඩම මඟින් පරිගණකයකට බාහිර උපාංග (I/O devices) සම්බන්ධ කරන ආකාරය, ඒ සඳහා භාවිතා කරන ක්‍රමවේද සහ වේගවත් දත්ත හුවමාරුවක් සඳහා යොදාගන්නා DMA තාක්ෂණය පිළිබඳව සාකච්ඡා කෙරේ. පහත දැක්වෙන සබැඳි (Links) භාවිතා කර අදාළ සටහන් කියවන්න.

### 1. 🔌 [I/O Interfaces & Ports](?note=ICT/1022/L12/01_IO_Interfaces_and_Ports.md)
* I/O Module එකක අවශ්‍යතාවය සහ එහි ව්‍යුහය.
* බාහිර උපාංගයකින් දත්ත ගැනීමේ පියවර.
* Input Port සහ Output Port වල ක්‍රියාකාරීත්වය.

### 2. 🗺️ [Memory-Mapped vs I/O-Mapped Interfaces](?note=ICT/1022/L12/02_Memory_Mapped_vs_IO_Mapped.md)
* I/O උපාංග සහ Memory එකවර පාලනය කරන ප්‍රධාන ක්‍රම 2.
* Memory-mapped I/O සහ I/O-mapped I/O අතර වෙනස.

### 3. 🚀 [Direct Memory Access (DMA)](?note=ICT/1022/L12/03_Direct_Memory_Access_DMA.md)
* Hard disk වැනි වේගවත් උපාංග සඳහා Programmed I/O සුදුසු නොවන්නේ ඇයි?
* DMA යනු කුමක්ද සහ එය ක්‍රියාත්මක වන පියවර.
* DMA Transfer Modes (Cycle Stealing සහ Block Transfer).

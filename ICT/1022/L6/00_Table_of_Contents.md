# 📚 L6: Instruction Set Architecture

මෙම පාඩම මඟින් Instruction Set Architecture (ISA) යනු කුමක්ද, කාලයත් සමඟ එය පරිණාමය වූ ආකාරය සහ රෙජිස්ටර් භාවිතා කිරීමේ වාසි සහ අවාසි පිළිබඳව සාකච්ඡා කෙරේ. පහත දැක්වෙන සබැඳි (Links) භාවිතා කර අදාළ සටහන් කියවන්න.

### 1. 📜 [Instruction Set Architecture (ISA) Basics](01_Instruction_Set_Architecture.md)
* ISA යනු කුමක්ද?
* නව උපදෙස් මාලාවක් සැලසුම් කිරීමේදී ඇතිවන ප්‍රධාන ගැටළු සහ සැලකිලිමත් විය යුතු කරුණු.

### 2. 📈 [Evolution of Instruction Sets](02_Evolution_of_ISAs.md)
* Accumulator Based, Stack Based, Memory-Memory, Register-Memory සහ Register-Register යන වාස්තු විද්‍යාවන් 5.
* ඒවායේ උපදෙස් ලියන ආකාරය (උදාහරණ සමඟ).

### 3. 🗃️ [General Purpose Registers (GPRs)](03_General_Purpose_Registers.md)
* පැරණි වාස්තු විද්‍යාවන් සහ නව වාස්තු විද්‍යාවන් අතර ඇති වෙනස.
* නව ප්‍රොසෙසර වල GPRs වැඩිපුර භාවිතා කිරීමට හේතු.
* Load-Store වාස්තු විද්‍යාවේ (RISC) වාසි සහ අවාසි.

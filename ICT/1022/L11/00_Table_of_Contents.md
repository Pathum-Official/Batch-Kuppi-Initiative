# 📚 L11: Memory Systems

මෙම පාඩම මඟින් පරිගණකයක මතක පද්ධතිය (Memory System), එහි විවිධ වර්ගීකරණයන්, ධූරාවලිය (Hierarchy) සහ කාර්යක්ෂමතාව ගණනය කිරීම පිළිබඳව සාකච්ඡා කෙරේ. පහත දැක්වෙන සබැඳි (Links) භාවිතා කර අදාළ සටහන් කියවන්න.

### 1. 🗄️ [Memory Characteristics & Classification](01_Memory_Characteristics.md)
* මතක චිපයක මූලික ව්‍යුහය සහ Connection ගණනය කිරීම.
* Volatile සහ Non-volatile මතකයන්.
* Random, Sequential සහ Direct Access.
* SRAM සහ DRAM අතර වෙනස.

### 2. 🛕 [Memory Hierarchy & Locality](02_Memory_Hierarchy_and_Locality.md)
* Processor-Memory Gap එක යනු කුමක්ද?
* Cache Memory සහ Virtual Memory හරහා ඊට ලැබෙන විසඳුම්.
* 90/10 Rule සහ ස්තරගත මතක ධූරාවලිය (Hierarchy).
* Temporal සහ Spatial Locality.

### 3. ⚡ [Memory Performance & Calculations](03_Performance_and_Calculations.md)

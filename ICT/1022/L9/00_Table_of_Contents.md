# 📚 L9: MIPS32 Instruction Set

මෙම පාඩම මඟින් MIPS32 ප්‍රොසෙසරයේ ඇති උපදෙස් මාලාව, ඒවා කාණ්ඩගත කර ඇති ආකාරය සහ එම උපදෙස් කේතනය කර ඇති (Encoding) ක්‍රම පිළිබඳව සාකච්ඡා කෙරේ. පහත දැක්වෙන සබැඳි (Links) භාවිතා කර අදාළ සටහන් කියවන්න.

* Load සහ Store උපදෙස් සහ වචන පෙළගැස්වීම (Alignment).
* Arithmetic සහ Logic උපදෙස්.
* Jump සහ Branch උපදෙස්.

### 2. ✖️➗ [Multiply and Divide Instructions in MIPS](02_MIPS_Multiply_and_Divide.md)

* පිළිතුර පිටතට ගන්නා `MFHI` සහ `MFLO` උපදෙස්.

# 📚 L5: Software and Architecture Types

මෙම පාඩම මඟින් මෘදුකාංග වර්ග, මෙහෙයුම් පද්ධතිවල කාර්යභාරය, පරිගණක වාස්තු විද්‍යාවේ ප්‍රධාන වර්ග සහ පයිප්ලයින් කිරීම (Pipelining) පිළිබඳව සාකච්ඡා කෙරේ. පහත දැක්වෙන සබැඳි (Links) භාවිතා කර අදාළ සටහන් කියවන්න.

### 1. 💻 [Software & Operating Systems](?note=ICT/1022/L5/01_Software_and_OS.md)
* මෘදුකාංග වර්ග: Application Software සහ System Software.
* Operating System (මෙහෙයුම් පද්ධතිය) යනු කුමක්ද?
* OS හි ප්‍රධාන අරමුණු (Multi-programming, Time-sharing, Real-time).

### 2. 🏛️ [Classification of Computer Architecture](?note=ICT/1022/L5/02_Architecture_Types.md)
* Von-Neumann Architecture සහ එහි අවහිරතා (Bottleneck).
* Harvard Architecture.
* Emerging Architectures (In-memory computing).

### 3. 🚀 [Pipelining in Executing Instructions](?note=ICT/1022/L5/03_Pipelining.md)
* උපදෙසක් ක්‍රියාත්මක වන අදියර 5 (IF, ID, EX, MEM, WB).
* Pipelining සංකල්පය.
* Pipelining සාර්ථක වීමට Harvard Architecture උදව් වන අයුරු.

# 01 Introduction to Programming - Summary

## 1. Core Concepts
*   **Programming (Coding):** A process of creating a set of instructions that tell a computer how to perform a task.
*   **Why it's important:** Automation, Problem Solving, Innovation, and it's a Foundational Skill.

## 2. Programming Languages
*   **Need for Languages:** Computers only understand `0s` and `1s` (electrical signals). Programming languages bridge the gap between human communication and computer communication.
*   **High-Level Languages:** 
    *   Easy for humans to read/write.
    *   Platform independent (Highly portable).
    *   Slower development but less control over hardware.
    *   *Examples:* Java, Python, C++, JavaScript.
*   **Low-Level Languages:** 
    *   Close to machine code, difficult to read.
    *   Machine dependent (Not portable).
    *   Fast performance and high control over hardware.
    *   *Examples:* Machine Language (binary `1101`), Assembly Language (uses words like `LOAD`, `ADD`).

## 3. Algorithms & Pseudocode
*   **Algorithm:** A finite, unambiguous, and correct sequence of well-defined instructions to solve a problem.
*   **Pseudocode:** A bridge between algorithms and code. Uses plain English + programming constructs (e.g., `READ num1`, `COMPUTE sum = num1 + num2`, `PRINT sum`).

## 4. Flow Charts
Visual representation of an algorithm using standard symbols:
*   **Oval:** Start / End
*   **Rectangle:** Process / Operation step
*   **Arrow:** Flow direction
*   **Diamond:** Decision (Yes/No)
*   **Parallelogram:** Input / Output operations

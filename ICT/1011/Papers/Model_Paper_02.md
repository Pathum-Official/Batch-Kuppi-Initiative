**Part (B) [15 Marks]**

### Answer 01
**Part (A) - Switch Case Calculator [20 Marks]**
```java
import java.util.Scanner;

public class SimpleCalculator {
    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);
        
        System.out.print("Enter first number: ");
        int num1 = input.nextInt();
        
        System.out.print("Enter second number: ");
        int num2 = input.nextInt();
        
        System.out.print("Enter operator (+, -, *, /): ");
        char operator = input.next().charAt(0); // Reading a character
        
        switch (operator) {
            case '+':
                System.out.println("Result: " + (num1 + num2));
                break;
            case '-':
                System.out.println("Result: " + (num1 - num2));
                break;
            case '*':
                System.out.println("Result: " + (num1 * num2));
                break;
            case '/':
                if (num2 == 0) {
                    System.out.println("Error: Cannot divide by zero");
                } else {
                    System.out.println("Result: " + (num1 / num2));
                }
                break;
            default:
                System.out.println("Error: Invalid Operator");
        }
        input.close();
    }
}
```
*(Marks allocation: Scanner & Input - 5 marks, Switch syntax & cases - 5 marks, Correct calculations & break statements - 5 marks, Division by zero & Default case - 5 marks)*

### Answer 02
**Part (A) - Recursion [15 Marks]**
```java
public static int sumOfNaturalNumbers(int n) {
    // 1. Base Case
    if (n == 1) { // Or if (n == 0) return 0;
        return 1;
    } 
    // 2. Recursive Step
    else {
        return n + sumOfNaturalNumbers(n - 1);
    }
}
```
*(Marks allocation: Base case correct - 5 marks, Recursive step correct - 10 marks)*

### Answer 03
**Part (A) - 2D Array Sum (Nested Loops) [20 Marks]**
```java
int[][] ticketPrices = {
    {100, 100, 100, 100},
    {200, 200, 200, 200},
    {300, 500, 500, 300}
};

int totalRevenue = 0;

for (int row = 0; row < ticketPrices.length; row++) {
    for (int col = 0; col < ticketPrices[row].length; col++) {
        totalRevenue += ticketPrices[row][col];
    }
}
System.out.println("Total Revenue: Rs. " + totalRevenue);
```
*(Marks allocation: Outer loop - 5 marks, Inner loop - 5 marks, Sum logic - 10 marks)*

**Part (B) - 1D Array processing from 2D Array [15 Marks]**

